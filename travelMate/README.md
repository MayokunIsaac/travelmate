# TravelMate 

A full-stack travel discovery and review platform inspired by TripAdvisor. 

## Technology Stack 

### Backend 
- Java 21
- Spring Boot 4 
- Spring Data JPA
- PostgreSQL

### Frontend
- React 
- JavaScript
- Vite 

## Features
- User registration and authentication
- Destination search and discovery
- Reviews and ratings for destinations
- Search and filter destinations
- Favourites

- frontend/
- database/
